GAME DESIGN DOCUMENT: BRAINROT MARKET TYCOON
Version: Final (Solo Dev Edition)Tech Stack: Roblox Lua (Argon / VS Code)

1. MINTING & VALUATION SYSTEM (THE BOX)
Description: Players spend currency to generate assets. Upon creation, the system immediately calculates an Intrinsic Value (Floor Price) for the Brainrot based on its RNG stats.

Input: Rizz Coins (Soft Currency).
RNG Mechanics (3 Layers):
Model: Skibidi, Nugget, Grimace, etc. (Rarity Multipliers: Common x1, Rare x2, Legendary x10).
Element: Plastic (x1), Gold (x3), Void (x5), Glitch (x10).
Size: Randomized float from 0.5 to 3.0.
Floor Price Calculation Formula:
Executed once immediately upon opening the box.
Floor Price = (Base Box Cost) * (Model Mult) * (Element Mult) * (Size Mult)
Example: Box Cost 100$ * Gold (x3) * Size 2.0 (x2) = **$600 Floor Price**.
Storage: This FloorPrice is saved permanently into the Item's data (IntrinsicValue) and never changes.
validation: player cannot open box if inventory is full

2. SHOWROOM (PASSIVE INCOME)
Description: The primary source of Rizz Coins. Brainrots generate income based on their calculated Floor Price.

Infrastructure: Each server will have 8 farm place, Each player gets a personal owned farm with max 6 brainrot placed down.
Mechanism:
Player places a Brainrot from Inventory into farm (brainrot will walk inside farm).
Server Script (Looping every 1s) calculates total income.

Income Formula:
Income/sec = (Item Floor Price) * 0.1
Example: An item with a $600 Floor Price generates $60/sec.
Implication: Higher valuation items = Higher passive income.
validation :can only place down in own farm and in farm range by left click and holding that item in hand, 
-after place brainrot down the item disapear in inventory
-can pick item up by left click to the brainrot again, when pick up hand must be empty and the brainrot go back to inventory
-datastore must save current brainrot in farm and their detail too to restore them back to inventory easily


3. INVENTORY (MANAGEMENT & VALUATION)
Description: Asset management UI, emphasizing price transparency.

UI Display:
-Brainrot name grid list (can scroll) .
-if player press on the icon player will hold that brainrot (press again will unhold) in hand and will showed up all the detail about brainrot at the right side and 2 buttons functions (quick sell, add to market)
Sorting Features:
-Sort by Floor Price (Most valuable).
-Sort by elements
add to market Mechanism: player press the button it will show up the board to input price (floor price will auto set first) then confirm
validation:  after confirm to add to market the item will disapear in inventory and save it to market (datastore should save current selling item detail so that can restore back to inventory easily)


4. QUICK SELL (LIQUIDITY)
Description: Sell items instantly to the System based on Floor Price
Mechanism:
Player selects Item -> Clicks "Quick Sell".
Cash Received = 50% of Floor Price.
Example: Gold Skibidi (Floor: $600) -> Quick Sell for $300.
Purpose: Ensures items are never worthless. Even if no one buys them on the market, players can liquidate them to recover capital.


5. TRADING & MARKETPLACE (P2P ECONOMY)
Description: Free market trading between players globally across server

Listing Mechanism:
UI: there will be 2 tabs : 
-personal item tabs : there will be list item user have added to market in inventory.
-global item across server that can be sort by floor price and element
-all the item when click will show all details about item: 
-in personal tabs when show detail will have a button to take down item
-in global tabs when show detail will have a button to buy item

Server Injection: The Server occasionally generates a item and lists it to function as a "Money Sink" (removing inflation).(rate to have rare item will lower open case)
validation: when take down an item global shop should update it rapidly and the item goes back to player inventory. 
-datastore should save current selling item detail so that can restore back to inventory easily


6. MARKET FLUCTUATIONS (THE SYNERGY HOUR)
Description: Temporary income buffs to stimulate trading and shelf reorganization.

Mechanism: Every 20 minutes, a random event triggers (Duration: 5-10 minutes).
Buff Rules (Random 1 of 2):
Single Buff: "All [GOLD] Element items generate x5(random) Income!"
Combo Buff: "If a Shelf contains both [MODEL NUGGET] and [ELEMENT VOID], both generate x20(random) Income!"
Impact:
When an event starts, the Passive Income formula (Section 2) applies the multiplier.
The Item's Floor Price remains unchanged, but its Utility Value spikes, causing players to rush to the market to buy specific types.
